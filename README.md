# Airline Loyalty Churn Project

## Overview
This 14‑day project analyzes airline loyalty program data to detect churn, engineer features, build predictive models, and design actionable retention strategies. The final deliverable is a polished Streamlit dashboard that integrates churn risk, segment profiles, geographic insights, and recommendations.

The project demonstrates both **technical depth** (data cleaning, feature engineering, modeling, dashboarding) and **business impact** (customer segmentation, churn reduction strategies, retention recommendations).

---

## Roadmap
- **Day 1**: Data cleaning & anomaly detection  
- **Day 2**: Feature engineering & churn flag creation  
- **Day 3**: Modeling & evaluation  
- **Day 4**: Hyperparameter tuning & feature importance

- **Day 6**: Ensemble methods  
- **Day 7**: Feature stability & interpretability

- **Day 13**: Dashboard enhancement & styling
